# StudyBuddy - Student Productivity App

## 📱 About
A mobile productivity app for students to manage tasks and study schedules.

## ✨ Features
- Task management with priority levels
- Subject-wise categorization
- Smooth animations (fade, slide, scale, rotate)
- Gesture interactions (drag and drop)
- Multi-screen navigation (Stack + Tab)

## 🛠️ Technologies
- React Native
- Expo
- React Navigation
- Animated API
- Gesture Handler
