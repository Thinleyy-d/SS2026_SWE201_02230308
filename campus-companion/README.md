# Campus Companion 📱

A mobile application built with React Native (Expo) to help new students quickly access important campus information including contacts, class schedules, and useful links.

## 📋 Overview

Campus Companion is designed specifically for first-year students to navigate campus life easily. The app provides:

- **Home Screen**: Quick access to all features with helpful tips for new students
- **Contacts Section**: Browse important campus contacts with detailed information
- **Schedule Viewer**: View weekly class schedules with day filtering
- **Campus Life**: Stay updated with announcements and access useful links

## 🚀 Features

- Clean, intuitive user interface
- Smooth navigation with bottom tabs
- Dynamic styling (highlight selected contacts)
- Responsive design that works on different screen sizes
- No backend required (uses static data)
- Platform-specific styling (iOS/Android)

## 📱 Screens

1. **Home** - Welcome message and quick navigation cards
2. **Contacts** - List of campus contacts with search/filter capability
3. **Contact Details** - Full contact information with click-to-call/email
4. **Schedule** - Weekly timetable with day filtering
5. **More** - Campus announcements and useful links

## 🛠️ Technologies Used

- React Native (Expo)
- React Navigation (Stack & Bottom Tabs)
- React Native Gesture Handler
- React Native Safe Area Context
